# teste-sitedeconversa💬 ChatWave PT

Um sistema de conversação web inspirado na experiência do WhatsApp, com a identidade visual do Discord e suporte para conversas em Português de Portugal (PT-PT).

📖 Sobre o projecto

O ChatWave é uma aplicação de conversação criada com HTML, CSS e JavaScript.

A aplicação permite:

Criar e adicionar contactos.
Pesquisar contactos.
Abrir diferentes conversas.
Enviar mensagens.
Receber respostas automáticas.
Guardar conversas no navegador.
Manter o histórico após actualizar a página.
Indicar contactos online.
Mostrar mensagens não lidas.
Utilizar a aplicação em computador, tablet e telemóvel.
Utilizar vocabulário e respostas em Português de Portugal.

Nota: esta versão funciona localmente no navegador. As respostas automáticas são simuladas e não representam uma inteligência artificial real.

❓ Perguntas frequentes
"O que é isto?"
Este é um sistema de conversação onde podes adicionar contactos, trocar mensagens e manter o histórico das conversas.

"Como envio uma mensagem?"
Escreve a mensagem no campo de texto e carrega no botão de enviar. Também podes carregar na tecla Enter.

"Como adiciono um contacto?"
Carrega no botão "+" no topo da lista de conversas, introduz o nome do contacto e, opcionalmente, o número de telefone.

"As mensagens ficam guardadas?"
Sim. Nesta versão, os contactos e as mensagens são guardados no armazenamento local do navegador.

"Posso fechar a página?"
Sim. As informações guardadas no navegador permanecem disponíveis quando voltares a abrir a aplicação, desde que os dados do navegador não sejam eliminados.

"Posso utilizar no telemóvel?"
Sim. A interface foi preparada para funcionar em ecrãs pequenos.

🧑‍💻 Perguntas sobre o projecto
"Que linguagem foi utilizada?"
O projecto utiliza HTML, CSS e JavaScript.

"Preciso de instalar alguma coisa?"
Não. Nesta versão podes abrir o ficheiro index.html directamente no navegador.

"Preciso de um servidor?"
Não para a versão local. Um servidor será necessário caso queiras transformar o projecto num serviço de conversação online entre vários utilizadores.

"As respostas são inteligência artificial?"
Não nesta versão. As respostas são simuladas através de JavaScript. Para utilizar inteligência artificial seria necessário integrar uma API ou outro sistema de IA.

🛠️ Respostas de erro
Mensagem vazia
Escreve uma mensagem antes de a enviar.

Contacto já existente
Este contacto já existe. Escolhe outro nome ou abre a conversa existente.

Contacto sem nome
É necessário indicar o nome do contacto.

Erro desconhecido
Não consegui compreender a tua mensagem. Podes tentar escrever de outra forma?

Por exemplo:

Isto permite que o sistema evolua de uma simples lista de palavras para um sistema de conversação baseado em intenções.
